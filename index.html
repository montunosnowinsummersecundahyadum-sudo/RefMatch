01 / Hackathon demo priorities

Three pieces.
One explainable demo.

The planned scope is a focused, interactive web demo—not a production platform.

01

Scoring + rules.

Calculate match risk, enforce hard eligibility filters, apply soft penalties, and rank fit with reasons traceable to the inputs.

Deterministic local engine ↗
02

Synthetic data.

Curate consistent fictional teams, fixtures, playing styles, rivalry signals, referee profiles, availability, and neutrality fields.

Fictional examples only ↗

Interactive web UI.

Connect the existing page to the scorer: explore the shortlist, inspect each rationale, and re-rank when availability changes.

03 / Demo scope

A focused demo.
Clear boundaries.

The current page previews the experience with fixed synthetic values. The scorer and its rules are planned work; no live ranking or real-world data is connected.

Meet the person building it ↗
01

Planned: real scoring logic.

A deterministic local engine will calculate risk, apply eligibility rules and penalties, and return explainable fit scores.

02

Now: illustrative interactions.

The shortlist, referee details, scores, and availability change are presentation examples, not calculated recommendations.

03

Not in this demo.

No external dataset, authentication, persistence, live language model, or production platform. Fit describes suitability, not match outcomes.
